# 原生子卡与节点导航

新卡用独立的 DSH 会话运行。SQLite 保存卡片关系、来源快照和原生会话 ID，聊天记录由 DSH 保存。旧卡继续使用原来的存储和生成接口。新卡从已完成的来源轮次取得文本，子卡围绕所选轮次或摘录，分支继承到指定轮次。打开空卡只准备上下文；原生输入框负责真正发送。

1. 先用隔离宿主验证新会话的预置、上下文、发送、主会话日志隔离和重启恢复。对 V1 数据库做增量升级，保留旧卡。
2. 用 DSH 的 `SessionProvider` 和嵌入式 `conversation.content` 挂载消息和原生编辑器。在覆盖层实测编辑器菜单、插件插槽、附件入口和逐层返回。
3. 由持久卡片关系绘制右侧节点图。当前卡填实，节点可用鼠标或键盘选择。返回共同祖先时保留其滚动和编辑状态。窄窗口给图保留独立的可滚动区域。
4. 验证旧卡兼容、从旧卡进入原生子卡、从原生卡建立分支、圆点跳转和最终安装包。
