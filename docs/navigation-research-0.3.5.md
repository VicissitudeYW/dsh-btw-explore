# Explore 导航调研与界面适配

2026-11-22 重新核对 Explore 当前公开交付的前端代码，并用浏览器查看首页演示。此次覆盖了正式 `/chat` 工作区；此前主要参考首页演示，遗漏了正式导航的布局、命中区域和位置动效。

## 核对到的实现

正式布局位于 `https://ai.explore.poker/_next/static/chunks/1766-d6900b4171ab54a7.js` 的模块 56857，SHA-256 为 `800cdd67707394c7a9afc2f7db93438342631bd89329c3816882281cdef61ef8`。节点和指针交互位于 `5568.ba1574b7e08e8677.js`，SHA-256 为 `4beb9f787862c26a5887a18f336f410bcc80c507ecfefff42051b99f3057728b`。资源路径都相对于 `https://ai.explore.poker/_next/static/chunks/`。

- 每层独立横向居中，根在下方，子层向上。普通层距 80px，同层中心间距 36.25px；分支与来源同层，并排列在其左侧。这个布局与逐行缩进的大纲不同。
- 普通视觉半径 14px，根半径 16.8px，透明命中半径 18.125px。视觉圆与点击区分开计算。
- 当前节点单色实心并有轻微光影；普通节点空心，来源路径加粗。暗色主题的当前节点为白色。悬停描边与当前态分开，当前态优先。
- 父子曲线从圆周出发，控制点位于层间。相邻同层关系直连，跨项关系画弧以避让节点。
- 独立透明画布采用原生滚动与指针平移，隐藏滚动条，周边留白允许边缘节点居中。位置变化使用约 320ms 插值，节点状态约 200ms。

浏览器现场确认了首页当前节点的白色实心、2px 描边、5px 光影及实际尺寸。演示中的划词和建分支操作没有产生可确认的新节点，因此多节点算法和正式工作区动效的结论来自静态代码核对，不能当作运行实测。

## 本插件的适配

保留独立右侧悬浮导航和 DSH 原生对话，不增加导航外框。采用 38px 同层间距、72px 层距、36px 点击区；桌面可视宽度 144px，中等窗口 108px，窄屏 72px。节点不随可视宽度缩小，宽树通过无滚动条拖动或滚轮浏览，键盘将目标节点带入视野。

子卡在来源上层，同轮分支与来源同层。当前节点实心，来源路径空心加粗，悬停或聚焦出现标题提示。节点位置、当前标记、状态和提示分别使用短过渡；系统要求减少动态时取消这些动效。

主动切卡与窗口变化将当前节点带入视野；后台数据刷新保留用户浏览锚点。本插件没有采用官网手动浏览三秒后自动归中的规则，以免打断正在查看其他分支的用户。左右键浏览同层，上下键浏览相邻层，Enter 或空格才打开卡片。

仅重建本插件已有的来源、子卡和分支关系。Explore 的分组、总结卡、排序、未读标记和云端服务不在此次范围。
