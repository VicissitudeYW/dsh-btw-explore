## 0.3.3 导航、卡片外层与动效

`npm test` 构建客户端并通过全部 43 项测试，零失败、零跳过。新增覆盖圆点的鼠标与键盘状态、外层操作和 16 项动效回归，包含快速连续切换、退出被重开打断、迟到请求、父卡实例与草稿保留，以及减少动态效果和缺少 WAAPI 时的同步切换。`git diff --check` 通过。

使用安装版 DSH `0.2.2-rc.5` 的隔离 Web profile 和本地模拟模型联测，同时加载 `dsh-message-toolbar` `1.11.0` 的已提交副本。宿主检查通过认证、原生子卡、流式回复、来源上下文隔离、主聊天历史不变和进程重启恢复。浏览器内验证了原生模型菜单，以及工具栏进入和退出回答编辑；按 Esc 先关闭菜单，再逐层返回卡片。

另外执行 `node test/host-smoke.mjs '--package=./dsh-btw-explore-0.3.3.tgz' --toolbar`，通过 DSH 插件命令从安装包安装到新的隔离 profile，以上宿主检查全部通过，命令以 0 退出。安装包包含四份样式、构建客户端和三张展示图，不含临时追踪表或动效审查帧。两轮临时宿主和模拟模型服务均已停止。

在真实宿主中划选回答文字，点击「探索引用」打开原生子卡，读取动画期间的样式并保存连续截图。进入过程中观察到 opacity 约 .837、scale 约 .992 和约 12 px 的来源方向位移，随后恢复稳定状态。返回、同级切换也观察到方向不同的中间状态。子卡创建初期当前环保留来源父卡，目标进入导航后直接移到子卡；最终重采的环位置为 `126 → 126 → 294.411 → 305.537 → 306`，未再出现误指返回入口或暂时消失。返回后父卡的未发送草稿和阅读位置保留。

独立代码审查发现并修复了关闭草稿后的迟到读取可能启动建卡、重开时聚焦早于解除 inert，以及草稿绑定与导航刷新间的当前环连续性问题。独立动效复审实际查看重采帧后给出可交付结论，没有剩余阻塞项。具体时序和边界见[动效验证](verification-motion-0.3.3.md)，参考资料见[Explore 调研](explore-polish-research.md)。

浅色、深色主题及 390 × 844 窄窗均已检查。390 像素宽时，文档的可视宽度和内容宽度均为 390，卡片为 314，圆点导航为 54，来源区为 282；来源区没有横向溢出。导航保持透明、无框和独立悬浮，标题提示显示在左侧。长引用和焦点环另以真实 CSS 页面检查。最终浏览器控制台没有警告或错误。

## 0.3.0 原生子卡与右侧节点图

使用安装版 DSH `0.2.2-rc.5`、隔离 Web profile 和本地模拟模型。宿主烟测检查空卡不触发生成、旧卡派生原生分支、只继承到指定轮次、从原生卡创建引用子卡，以及主聊天的事件日志保持一致。宿主进程重启后重新读取原生对话和卡片映射。

浏览器中用子卡原生输入框发送，打开模型菜单和附件或指令菜单。加载本机 `dsh-message-toolbar` 后，可以在子卡进入与退出回答编辑。验证按 Esc 先收起原生菜单，返回时回到来源操作，底层卡退出 Tab 焦点顺序。通过原生消息划选「分块返回」创建子卡，确认引用出现在来源区。点击同级节点，再回父卡，原生草稿仍在。关闭覆盖层后可从「探索」卡片树重开原生对话。

390 像素宽的浏览器中覆盖页占满视口，原生输入和节点图可用，覆盖页没有横向溢出。客户端回归测试覆盖节点图轮询刷新时保持手动滚动、改变窗宽时带回当前节点，以及父卡返回时保留阅读位置。
