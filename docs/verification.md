# dsh-btw-explore 验证记录

## 0.3.1 独立圆点导航

`npm test` 通过 24 项测试。客户端回归测试覆盖导航位于子卡外、连续点选以最后一次为准，以及回到已打开的父卡时保留草稿和阅读位置。

从 `0.3.1` 安装包启动 DSH `0.2.2-rc.5` 的隔离 Web profile，并同时加载 `dsh-message-toolbar`。在浏览器中点击同级卡与父卡圆点，确认当前节点和卡片一致，父卡的原生草稿保留，`Esc` 会先收起原生模型菜单。浏览器在切换同级卡和返回父卡时都测到了动画中间帧。390 像素宽时，导航与卡片保有 8 像素间隔，原生输入框可用，页面没有横向溢出。

[独立悬浮的圆点导航](showcase/native-card-map.jpg)。截图使用本地模拟模型与测试会话。

## 0.3.0 原生子卡与右侧节点图

使用安装版 DSH `0.2.2-rc.5`、隔离 Web profile 和本地模拟模型。宿主烟测检查空卡不触发生成、旧卡派生原生分支、只继承到指定轮次、从原生卡创建引用子卡，以及主聊天的事件日志保持一致。宿主进程重启后重新读取原生对话和卡片映射。

浏览器中用子卡原生输入框发送，打开模型菜单和附件或指令菜单。加载本机 `dsh-message-toolbar` 后，可以在子卡进入与退出回答编辑。验证按 Esc 先收起原生菜单，返回时回到来源操作，底层卡退出 Tab 焦点顺序。通过原生消息划选「分块返回」创建子卡，确认引用出现在来源区。点击同级节点，再回父卡，原生草稿仍在。关闭覆盖层后可从「探索」卡片树重开原生对话。

390 像素宽的浏览器中覆盖页占满视口，原生输入和节点图可用，覆盖页没有横向溢出。客户端回归测试覆盖节点图轮询刷新时保持手动滚动、改变窗宽时带回当前节点，以及父卡返回时保留阅读位置。

## 0.2.0 覆盖式子页面

在 DSH `0.2.2-rc.5` 的隔离 Web profile 和本地测试模型上验证。`npm test` 通过 23 项测试。安装包烟测覆盖认证、流式回答、分支上下文、会话隔离和宿主重启恢复。

Edge 中从主聊天回答、划词引用以及已有卡片的轮次打开覆盖页。测试了两层页面逐层返回，父卡滚动位置和未提交草稿保持原样。消息操作返回后焦点回到按钮，划词返回后回到原消息。测试还覆盖 `Esc`、`Ctrl + Enter`、防止子页打开时触发宿主新建会话和搜索、关闭后从卡片树回看，以及窄窗全页呈现与横向溢出检查。

[子页覆盖在父卡及原聊天之上](showcase/child-page.jpg)。图片使用隔离测试数据。

## 0.1.0 卡片树

2026-11-21 在 Windows 上验收。宿主使用本机安装的 DSH `0.2.2-rc.5`，测试进程使用临时 Web profile、独立数据库和仅监听本机的测试模型服务。

| 验证 | 检查内容 |
| --- | --- |
| `npm test` | 构建客户端并执行 21 项测试。覆盖选区与消息入口、窄窗菜单切换、精确来源、上下文裁剪、主会话隔离、SQLite 恢复、网络响应过期、停止重试与删除保护。 |
| `node test/host-smoke.mjs` | 使用安装版宿主。检查浏览器 cookie 认证、插件路由、DSH 模型适配器到测试服务的 SSE、持久化与主会话事件一致性。 |
| `node test/host-smoke.mjs '--package=./dsh-btw-explore-0.1.0.tgz'` | 使用相同用例验证从本地发布包安装。读取测试服务实际收到的聊天正文，确认旁路排除了宿主提示，分支继承第一轮且未带入随后一轮。停止宿主并重新启动后，深比较卡片、追问、分支和主会话事件。 |
| Edge 浏览器 | 在真实宿主页面打开原生视图、标题栏按钮和回答入口，划词打开带原文的预览。完成预览保存、卡内续问、创建子卡、从第一轮创建分支和回看来源。刷新后还原视图、树与已选卡片。390 像素视口中确认更多菜单切换、树可折叠及阅读区无横向溢出。 |

[真实宿主截图](showcase/card-tree.png)展示一张多轮根卡及其子卡和分支。截图中的问题、答案和会话均为合成测试数据。

验收范围为隔离 Web profile 和本地测试模型。实际桌面界面和真实模型提供商未参与本次验收。选区浮层被原生引用先占用时的并排兼容由客户端回归测试覆盖。主聊天原文定位依赖 DSH 当前能渲染的消息范围。
