# 卡片界面与动效打磨

## 本次目标

沿用 DSH 的对话区、输入框、模型菜单和对话插件。打磨插件提供的路径、返回操作、移除操作、来源引用，以及独立浮在右侧的圆点导航。保留浅色、深色和窄窗使用方式，面向用户的文字保持简短。

圆点导航没有外框或背景面板，也不产生横向滚动条。用细连线、小幅缩进与当前路径状态表达关系；指针或键盘聚焦时给出标题提示，圆点的点击区域保持稳定。

## 实现选择

保留现有中性色与 DSH 主题变量，以文字层级、统一线性图标、间距和交互状态来提高完成度。独立的强色主题会与对话区割裂，大尺寸卡片式导航也与已有的悬浮大纲要求不符，因此本轮不采用。原生对话区继续交给 DSH 渲染。

顶部保持路径与当前标题的主次，返回按钮带方向图标，移除操作默认低权重且保留确认。来源引用采用无框的轻排版，以图标、标题和摘录表达关系。

## 动效

- 重点：划词打开子卡时，以选区或来源操作的位置为起点作短距离展开，建立来源与子卡的联系。
- 连续性：前进、回到父卡、同级切换采用有方向的位移与淡入；退出比进入更快。保留共同祖先的真实节点和编辑状态。
- 反馈：悬停显示标题，圆点内部轻放大，聚焦明确可见，按压反馈即时，不移动点击区域。
- 预算：进入与切换约 180–230 毫秒，退出约 150 毫秒。只在交互时播放，避免循环、弹跳和大面积滤镜；快速连续操作可以中断。
- 减少动态效果时同步更新页面状态，保留静态的当前点和焦点提示，不等待退场计时。

## 协作与验收

研究、卡片外层、覆盖层动效分别由独立代理负责，主代理负责导航、样式接入、统一检查与交付。各代理限制编辑文件，避免共享文件冲突。以现有测试、动画生命周期回归及隔离 DSH 页面验证为准，检查鼠标、键盘、划词、连续切换、父卡状态、浅深主题与窄窗。最后更新展示素材、打包并推送 main。
