# DSH 旁路卡片树设计

「探索」是 DSH 当前会话的独立视图。树中的每张卡有自己的问答，可以继续追问，从已完成的某轮建立子卡或分支。划选主聊天正文可打开带引用的预览。未保存的问答在树中标记为「预览」，可以回看、保存或丢弃。

考虑过用临时 child agent 或独立 DSH 会话承载卡片。前者会产生宿主的子任务生命周期，后者会把旁路卡片变成会话列表中的条目。首版选择插件自有 SQLite 数据库和 `ctx.llm.stream()`，以便单独树形组织卡片、固定消息边界，并与主聊天的输入和事件日志隔离。DB 位于 DSH home 下，各会话按 ID 分区。

| 入口 | 固定的起始上下文 |
| --- | --- |
| 新建根卡 | 主会话最近的完整文本轮次。锚定某条消息时，以它为边界；划词同时保存摘录。|
| 从一轮新建子卡 | 来源问题与对应回答，划词时只带选中的回答部分。|
| 从一轮新建分支 | 来源卡固定的起始上下文，以及从第一轮到所选轮的有效问答。|
| 卡内追问 | 该卡的起始上下文和该卡此前有效的问答。|

模型输入保留最近的有限文本，详情显示裁剪状态。失败或停止的半截回答保留作阅读，但不带入后续请求。树节点、来源和问答在启动生成前写盘；模型增量定期保存，关闭界面不取消后台任务。停止立刻终止该轮写入，意外退出后过期的任务显示为中断。可重试最新失败轮，移除分支时连带移除后代。

首版界面采用可折叠的树和卡片阅读区。Explore 的同级发散、总结卡、画布整理和云同步作为后续功能点。实测目标为 DSH 0.2.2-rc.5 的 Web 与 Desktop 共用客户端。

## 0.2.0 覆盖式子页面

从主聊天消息、文字引用、卡片轮次启动旁问时，在来源上方打开单独的阅读页。选择覆盖层可以同时保留源页面的滚动和草稿，并为子卡留出独立的阅读和输入空间。卡片树仍是已提交卡片的回看入口。

会话标题栏承载浏览器原生模态对话框。每层独立持有阅读和编辑状态，关闭顶部只返回紧邻的一层。可用返回按钮或 `Esc`，点击遮罩保留当前层。标题栏卸载时关闭该会话的覆盖层。提交之后的生成属于宿主，关闭子页不停止生成，也不会更改后台树上原来选中的卡片。卡片数据和原有存储规则保持一致。

## 0.3.0 原生对话和节点图

新卡有独立的普通 DSH 会话。覆盖页挂载原生消息、编辑器和对话插槽。覆盖页与原生菜单都挂在应用根节点外部，父卡和主界面在子页打开时退出焦点顺序。关闭顶部子页时还原来源元素的焦点和滚动位置。旧卡保留原来的文字问答，也可以作为原生卡的来源。

右侧图按来源关系排布，入口节点回到打开覆盖页之前的页面。节点跳转保留仍属于目标路径的已打开祖先。数据刷新保持手动浏览位置，当前卡变化或窗口缩放时将当前节点带回视野。发过消息的原生子卡也由 DSH 的会话列表管理，移除卡片关系时保留 DSH 对话记录。

## 0.3.5 二维悬浮导航

正式 Explore 前端的重新调研见 [导航调研记录](navigation-research-0.3.5.md)。圆点采用真正的分层关系布局：入口在下，子卡向上，同轮分支与来源同层向左展开。各层横向居中，普通节点直径 24px，入口 28px，独立点击区 36px。当前节点单色实心，来源路径加粗，普通节点空心；提示分为标题和关系信息。

导航维持独立透明浮层，没有外框或面板。桌面宽 144px、中等窗口 108px、窄屏 72px；内容保持原尺寸，宽树可拖动和滚动，不显示滚动条。周边留白使任意边缘节点都可以居中。方向键只移动焦点，Enter 或空格切卡；单个 Tab 入口避免大量节点占用主对话键盘顺序。

节点和曲线约 320ms 过渡，状态约 200ms，提示约 160ms。兼容路径命令之间的曲线位置可以插值，拓扑改变不保证全程连续。节点明确设置圆形角形状，避免宿主的全局超椭圆样式改变轮廓。

拖动超过 5px 抑制点击，结束后清理手势。鼠标按下触发的默认聚焦不移动视野；被动数据更新优先保持实际可见的浏览节点，聚焦节点移除后回到存活来源。主动切换才将新目标带入视野，不定时夺回手动浏览位置。减少动态效果时取消导航过渡，保留焦点和路径状态。原生页面挂载和对话生命周期继续由现有页面栈管理。
